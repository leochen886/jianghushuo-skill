# 按本包语境解释术语

| 术语 | 本材料中的含义 | 使用条件 |
|---|---|---|
| 真实需求 | 具体人已经遇到问题、尝试解决并愿投入重要成本 | 感谢和点赞不单独证明支付 |
| 最小闭环 | 从发现问题到完成一次交付并取得真实反馈 | 做宣传不是完成交付；付费和非付费分别记 |
| 能力切片 | 能让对方体验或判断解决能力的小成果/过程 | 真实、可使用；没有客户案例可标演示 |
| 微产品 | 聚焦一个问题的小册子、模板、流程或工具 | 完整可用而非仅摘抄；支付仍需验证 |
| 免费共创 | 在有限帮助中识别共同问题并完善产品 | 有范围；不能追溯原免费约定收钱 |
| 信息差 | 把一个群体的知识翻译为另一群体能用的方案 | 只领先知道术语不足；需真理解、可用 |
| 生意拆解 | 查清谁付钱、交付什么、如何接触成交和付出什么成本 | 自述和未知分开，不猜净利润 |
| 复购 | 同一期间客户再次购买的行为 | 率、次数、金额口径不同；不能直接当订单倍数 |
| 资产/系统 | 留下可反复调用、维护和改进的步骤、成果或工具 | 不是文件越多越好；自动化需要实际走通 |
| 错题本 | 保存失败场景、症状、版本、反馈、解释和下一次改法 | AI解释为假设，真实反馈才是经验材料 |
| 清零重选 | 暂去旧投入/身份理由，检查现在是否仍愿意进入 | 不会消灭合同、退出成本和生活约束 |
| 时薪 | 对时间、钱与精力取舍的条件化参照 | 自定价不等于有订单；先满足生存条件 |
| 框架/结构/阶段 | 分别是重复思考框架、某作品组织方式、进化路线 | 按所需任务择一，不能凭成功结局补完整过程 |
| 来源验证 | 精确原话能在对应转写定位 | 不等于外部事实核验 |
| 任务演练 | 对新输入实际完成表格、实验、稿件或流程 | 不等于在现实中获得客户或盈利 |

更细的时期术语保存在包根resources/methods/research-reference.json；遇到转写疑问时回查完整来源，不凭术语名从其他作者补造规则。

## 业务杠杆、复利与成果控制

- **业务杠杆**：软件、标准产品、内容或协作让同一成果服务更多人，个人工时不随每单等比例增长；仍须算维护与例外劳动。本包不指借贷杠杆。
- **复利**：已有知识、成果、信任或触达条件帮助后续工作，新反馈又升级原资产的积累机制；复制、长期坚持或资料变多并不能单独证明复利，更不能保证收益增长。
- **新增成本/边际成本**：增加一位用户或一份交付增加的费用与劳动，含售后、平台、算力和返工；与首次制作成本、固定维护成本分开。原文“零成本”不能自动用于预测。
- **所有权与控制条件**：检查原创成果、版权或可使用许可、能持续维护的产品与允许保存的关系；依赖平台或第三方材料须另列。用户关系不等于可以任意使用个人信息，整理工具不等于拥有工具版权。
- **清零行动**：原文指做完后难以留下可复用成果的劳动；与项目筛查中为排除沉没成本的“清零重选”不同。必要履约仍须完成。
