# 决策规则速查 — 姜胡说挣钱方法论

| 能力 | 一句话规则 |
|---|---|
| 业务杠杆与复利结构 | 先核对新增劳动、可控制成果与反馈升级，再用符合结构约束的小动作验证需求 |
| 能力与付费问题匹配 | 对齐人群、问题与组合能力，先筛用户约束及可积累结构，再选能检验的机会 |
| 发现并核对真实需求 | 从经历、已有替代和行为提取卡点，再查切换成本与真实投入 |
| 拆解已有生意 | 拆谁付钱、交付什么、如何成交和付出什么成本，未知保留 |
| 可退出的最小验证 | 在预算和履约范围内测试主要未知，用真实反馈决定继续或停 |
| 经营数字与口径 | 同期间拆订单和成本，未知成本不能写成净利润 |
| 让真实能力可见 | 用样品和真实过程展示能解决什么，形式按人群和约束选 |
| 从问题形成内容 | 用用户语言提出卡点、兑现解决过程，以目标反馈改进内容 |
| 交付流程与成果复用 | 从多次完成提炼稳定步骤、变量和人工判断，保留检查与异常 |
| 行动复盘与版本纠偏 | 对照计划、动作、结果，检验一个主要变量并留下错题记录 |
| 成交到交付的流程 | 让了解、报价、付款、订单、交付和支持走通，配置状态诚实标记 |
| 相近标杆的迁移 | 按需要借鉴框架、同期结构或阶段路线，分离可迁移条件和未知运气 |
| 跨人群知识转译 | 把真理解的专业常识转成另一群体能完成任务的低摩擦方案 |
| 时间与委托的取舍 | 满足生存约束后比较钱、时间、精力、机会与质量，释放时间有去处 |
| 免费共创到小额收费 | 记录有限帮助的真实结果，按阶段尝试收费，感谢不能替代支付 |
| 项目筛查与退出 | 看未来结果、投入和验证节点，保基本盘并预设退出与收尾条件 |
| 多篇经验重构为执行框架 | 纠错合并已有解答，删冗补缺后形成最少必要框架，再以新场景验证 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
